# Semesta

Voxel action RPG 2.5D in the browser (the in-world town is **Anavela Universe**). three.js + Vite, vanilla JS ES modules. All pixel art (textures, sprites, icons) is generated procedurally via 16px canvas. Music & SFX are fully synthesized with WebAudio — no audio files. Exceptions: `logoasset/semesta.png` (logo) & `logoasset/nxrmascott.png` (mascot) imported by `src/ui/menu.js`, plus two Google webfonts (`Pixelify Sans` body via `--font-body`, `Silkscreen` display titles via `--font-display`, linked in index.html).

Art direction: cozy Stardew-Valley-ish palette (lush greens, warm earth, turquoise water), chibi big-head characters (NOT minecraft proportions), cute-critter enemies/NPCs/pets with big glossy pixel eyes (Pokemon / Pokopia / Animal Crossing energy).

## Running

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
npm run preview
```

## Structure

- `src/main.js` — bootstrap: Opening (menu.js) → Character Creation → **cinematic load screen** (loadscreen.js; `setBoot(pct, label)` now reports a real stage name for every step: opening the canvas → painting the pixel tiles → raising the terrain → carving the coastline and the sea → planting the forest → filling the lakes and the ocean → waking the villagers → **forging every item icon** → **compiling shaders** (`renderer.compile` + one throwaway render) → tuning the orchestra — the last three are a deliberate PREWARM so the first bag open / first swing / first night doesn't hitch) → build world → game loop; wires the **dual-action interact system** (`gatherInteractions()` collects all nearby actions by priority → `interactPair()` returns a PRIMARY + a distinct-`kind` SECONDARY, so farming's Plant/Harvest never fights a villager's Talk for one button: **F / ★ = primary, R / green ✦ button = secondary**; landmarks beat wandering NPCs, farm plots get their own slot), auto-aim, jump (Space), mounts (M), world map (N), wardrobe (O), **Teleport, TWO destinations** (**T / ⌂ GO HOME** and **Y / ⛺ BASECAMP** — 1.6s stand-still channel, 20s cd; home lands via `moveToClearSpot` on a clear cell BESIDE the house door, basecamp always lands on `terrain.spawn`, and home falls back to the basecamp if you own no house. They are separate because they are wanted at different moments — the shops, forge and gacha are in town, your crops are at home — and one button meant that once you owned a house you could never fast-travel to town again), AFK fishing (G), **AFK Auto-Battle (B / ⚔AUTO)**, world boss scheduler (180s), safe zones (village/camps/homes — `inSafeZone`), economy/cooking/estate APIs, **gacha v2** (six-tier weighted roll + soft pity `gacha.pity` — +weight to epic+ after 8 dry rolls; tier pools in `GACHA_POOLS`; owned uniques refund coins per `RARITY[r].refund`), **level-up celebration** (`levelRewards`: coins every level, tonics each 3rd, an unowned cosmetic each 5th, golden shockwave/fountain FX + `hud.levelUp` overlay + `levelup_big` fanfare), out-of-combat auto-heal, save v3 (now incl. `wardrobe`, `gachaPity`); `decor.clearArea` is called for camps/landmarks/lands at build & after `estate.build` so scenery never clips structures, and `moveToClearSpot` frees the player from fresh house footprints
- `src/ui/docs.js` — **THE SEMESTA GUIDE**, reachable from the main menu (📖 HOW TO PLAY) *before* you commit to a character, because a new player's questions all arrive before NEW ADVENTURE. Categorised sidebar (GETTING STARTED / THE WORLD / CORE SYSTEMS / LIVELIHOODS / PROGRESSION / ECONOMY / GAMEFI / HELP) + long-form sections, built from ONE `CATEGORIES` data array so a topic is one entry not two; `call('do'|'dont', …)` callouts and `kv()` tables. 23 sections. The GAMEFI chapter states plainly that **nothing is on-chain yet** and that anyone asking you to connect a wallet today is not us — a guide that oversells is worse than none. Sidebar jumps are INSTANT on purpose: both `scrollTo({behavior:'smooth'})` and CSS `scroll-behavior` are silently inert in a throttled tab (measured: a jump to 800 landed at 0), and offsets are measured off `getBoundingClientRect` because `.dmain` is not its sections' offsetParent
- `src/gfx/signs.js` — **signboards**: a 5x7 bitmap font defined in-file (not `fillText` — the webfonts may not have loaded when the world builds, and a real bitmap font upscales to crisp blocks) plus `makeSignTexture(label, glyph, accent)` painting a three-plank board with carved lettering and a tiny pixel pictogram. `buildSignboard()` in npcs.js hangs it from two posts on chains. The plaza had three matching daises with no way to tell shop from forge from capsule machine; there are now boards for **SHOP / FORGE / GACHA** just outside each station on its own avenue, and **FARM** by the field
- `src/ui/menu.js` — opening loading splash (pixel sky + logo + "BUILD FOR RIALO" badge; boot screen carries "◆ BUILD FOR RIALO ◆" too) → main menu (New / Continue / **Roadmap** / About), with the collapsible **graphics panel pinned right**. The **ROADMAP** modal lays out four numbered phases: 01 TOKEN LAUNCHPAD (Semesta launches on the Semesta Launchpad, 1B supply), 02 HOLD TO PLAY (min. 1,000 SEMESTA), 03 TOKEN GACHA (gacha accepts SEMESTA alongside gold), 04 GENESIS NFT (free mint for active players) + the Rialo badge. The About content lives in **`src/ui/about.js`** (`aboutInner(logoSrc)` + `paintAboutRialo()` + `ABOUT_BADGE_CSS`), shared VERBATIM by the menu modal AND the in-game About panel so credits never drift: SEMESTA logo, **THE TEAM** (Nxrskyaa / GAME DEVELOPER → x.com/nxrskyaa, Dikzzy / GAME TESTER & BUG HUNTER → x.com/diikzzyy__, Baster / TECHNICAL GAME DEVELOPER → x.com/Bas_Basterx — equal-size rows), and a **BUILD FOR RIALO badge with the procedural Rialo mark** (canvas painted by `paintRialoMark`); exports logoUrl/mascotUrl
- `src/gfx/quality.js` — **graphics quality system** (`semesta.gfx.v1`): 4 presets (**low/medium/high/ultra**) + per-group overrides across 5 groups — `res` (render scale 0.6/0.8/1.0/1.25), `shadows` (off/soft 1536/sharp 3072), `fx` (particle+weather+firefly scale, trails), `detail` (decor density, lantern lights, ambient critters, water segments, fog — **`live: false`**, baked at world build) and `view` (draw distance 110/160/220). Autodetects a starting preset from `hardwareConcurrency`/`deviceMemory`. `onQualityChange` re-applies live groups instantly; `buildSnapshot()`/`pendingAgainst()` drive honest **NEXT RUN** tags on the non-live group. NOTE: there is deliberately no "texture" slider — all art is procedural 16px canvas, so it would be pure theatre
- `src/ui/gfxpanel.js` — the quality panel, one component with two homes: the **opening/loading screen** (pinned to the RIGHT edge — `right: max(3%, 14px)`, and **collapsible**: a phone opens to a small ⚙ GRAPHICS tab so it can never cover the menu column, expanding to a top-right plate) and the in-game ☰ → GRAPHICS panel (`title: false`, flowed statically inside the game panel). Per-row hint line explains what each knob actually costs
- `src/systems/story.js` — **THE STORY OF ANAVELA**, in 7 chapters. The arc: you are the last apprentice of the **Lanternkeepers**, the order that kept Anavela's lights burning; the lights went out, the wilds walked back in, and relighting them is how the world is put right — ending on "we were never keeping the dark out, we were keeping the place worth coming back to". Every chapter gates on a condition the game ALREADY tracks (level, kills, `swam`, `visitedIsland`, `hasHome`), so `story.check(ctx)` is called once a second with live state and the story advances by PLAYING rather than by scripted triggers. Each beat pays a reward (the finale hands over the Nimbus mount) and sets `state.hint`, the one-line nudge for what to do next. `hud.showStory` renders it as a parchment-and-gold card that **waits for the player** — it used to dismiss itself after 16 seconds, so the card vanished mid-sentence; a story beat that deletes itself while you are reading it is worse than no story. It now closes only on CONTINUE, carries a `NEXT ·` line naming what to do, and `hud.getStoryLog()` keeps every chapter shown, and it counts as a menu overlay so it blocks the mobile joystick
- `src/systems/gamepass.js` — **GAMEPASS**, a season pass bought with gold you earned rather than money. 30 tiers, 100 pass-XP each, and THREE reward rows: `free` (always claimable, so nobody is locked out), `basic` (**1,000c**, +10% XP) and `premium` (**3,000c**, +25% XP / +15% luck / +10% coins). Upgrading basic→premium only costs the difference. Pass XP comes from the same events the dailies use (`PASS_XP` weights kill 4 / boss 120 / chest 25 / quest 60 …) so the pass rewards playing rather than one grind loop; rewards are claimable retroactively for every tier already reached, with a CLAIM ALL. Track tops out at Aurora (mythic mount) on premium tier 30. Same contract as dailies: rewards are DATA here, granted by a caller-supplied `grant()`
- `src/systems/dailies.js` — retention trio sharing one save blob: **30-day check-in** (`CHECKIN_DAYS`, escalating rewards — coins/mats early, cosmetics at d7/14/20/21/26/29, **Pebble mount at d30**; rolls over at local midnight, a >1-day gap resets the streak), **play-time milestones** (`PLAYTIME_TIERS` at 5/15/30/45/60 min, per session) and a **daily quest board** (3 drawn from a 12-quest pool by a day-seeded shuffle so refreshing can't reroll it). Rewards are described here as data and granted by a single caller-supplied `grant()` — the module never touches the inventory. main.js feeds it `kill/boss/fish/chest/gather/plant/harvest/cook/forge/skill/gacha` events and `hud.setMenuBadge(dailies.pending())` pulses a "!" on ☰
- `src/ui/loadscreen.js` — **cinematic loading screen**: five procedural pixel VIGNETTES (320x180 canvas upscaled `pixelated`, one picked at random per boot) — **dawn** over the village (climbing sun, drifting clouds, birds, chimney smoke), **night** on the lantern road (stars, cratered moon, glowing stone lanterns, dancing fireflies), **winter** (drifting aurora bands, frost conifers, snowfall), **sea** (sunset ocean, island silhouettes w/ leaning palms, scrolling wave bands, a jetski cutting a wake), **festival** (bonfire w/ stacked flame tongues, swaying chōchin, 4 chibi critters hopping, rising embers). Shared grammar: sky gradient → layered silhouette ridges → one focal element → one particle system. Over it: the SEMESTA wordmark, the scene's name, an HONEST 24-cell segmented bar driven by the real build stages (not a timer), a rotating DID-YOU-KNOW tip that doubles as a soft tutorial, scanline+vignette veil, and the BUILD FOR RIALO line. `createLoadScreen({logoSrc, vignette})` → `{ el, stage(label, pct), done(), dispose() }`
- `src/ui/worldmap.js` — fullscreen world map overlay (N / tap minimap): village ⌂, camps ▲, land ◎ w/ "FOR SALE"/"YOUR LAND" labels, built homes as big pulsing ⌂ + "YOUR HOME" label, quest !, boss ◆, player arrow; **tap the map to drop a ⚑ waypoint mark** (tap it again to clear) — `getPin()/clearPin()`; main.js shows a HUD beacon chip (camera-relative arrow + distance via `hud.setBeacon`), draws the flag on the minimap, and auto-clears w/ a toast when the player arrives (<2.5u); explicit ✕ close button (backdrop click also closes — clicking the map no longer closes it)
- `src/world/camps.js` — 6 rest camps (campfire+tent+bench, quadrants + sparse mid-edges) each with a Ranger fox-NPC (talk → full heal): safe zones, fast heal, cooking stations
- `src/world/gather.js` — gatherable nodes: pale banded BIRCH trees (chop → hardwood) & glowing-vein ORE boulders (mine → iron ore/forge stones), 3 hits, respawn
- **CALM WATER**: the two lakes (radius + 5) and are registered as sanctuaries in `inSafeZone`, so the enemy AI's existing rules apply — no spawns, repelled at the boundary, aggro'd monsters disengage and wander off. Verified: 61 monsters force-spawned at the zones, **0** ended up inside one
- `src/systems/farming.js` — 8 farm plots by the village (2 free, buy more): plant seeds → 3 growth stages → harvest crops to sell
- `src/systems/housing.js` — 4 land parcels (250c) + 3 house designs (Cabin/Cottage/Villa) built from hardwood+iron ore+coins; homes are safe zones that heal. Each parcel has a floating billboard label ("LAND FOR SALE" → "YOUR LAND"); built homes & land show as markers on the minimap AND world map; a scout quest (`home_sweet_home`) tutorializes the buy→gather→build flow, and the Estate panel shows numbered steps
- `src/systems/skilltree.js` — **LIFE SKILLS**: fishing, farming and cooking each level on their own XP and pay a point per level, spent on a small tree. Nodes have to change how the activity PLAYS, not add a hidden percentage — a wider bite window, a second fish on one cast, an extra crop, the seed back, a plant left standing, two portions from one pot. **Mythic fish are gated behind a single 3-point node**, the only thing in the game that unlocks them. Everything is data plus `bonus(skill, key)`, so callers ask "how much extra?" and never need to know what a node is. Panel: ☰ → LIFE SKILLS or **L**
- `src/world/wind.js` — **WIND**: ONE vector that wanders in heading and strength and throws occasional gusts. There are deliberately **NO drifting motes** — a first pass carried leaves across the screen and they read as debris ON THE CAMERA rather than in the world, constantly crossing the middle of the view in a game you are trying to aim in. Wind is better felt through what it MOVES than through litter flying past your face. The point is that everything leans off the SAME source (Rialo banner, paper lanterns, flower beds) — that coherence is what separates weather from every prop wobbling on its own private sine. `sway(phase)` hands out a value already in the right rhythm; mote count scales off the weather budget and reaches zero at the bottom of it
- `src/systems/classes.js` — **THE CLASS LADDER**. Everybody starts as **ORIGIN**: one plain sword and `skills: []` — NOTHING. That is the point: a hero who begins with three abilities has nothing to earn, and the first ten levels are where you learn that swinging, dodging and reading a tell is the actual game. At **Lv10** (`AWAKEN_LEVEL`) **Grand Master Vell** (owl NPC in the plaza) awakens you into one of six (`ADVANCED_CLASSES`): **Warrior** (a `branches` pick — sword+shield or the heavier, wider **axe**), **Archer**, **Mage**, **Priest**, **Assassin**, **Summoner** (a **cannon** — the only basic attack with an area). The level-up only NUDGES; the ritual needs a walk to the NPC, because being yanked into an irreversible choice by a level-up you got mid-fight is the wrong moment to be asked. Plus all customization constants (**16 skins, 24 hair styles** incl. `BALD_STYLE`, **20 hair colors, 12 eye colors, 14 face accessories, 10 outfit styles**)
- `src/systems/classtree.js` — per-class **SKILL TREES**: 3 tiers gated on level (10/16/24), 7 nodes each. **Learning is permanent, slotting is free** — you spend points to learn and then equip any 3 into the action bar, so experimenting with a loadout never costs the points you ground for. Deliberately no "spend 5 here to open the next", which just means everybody looks up the one correct path. No node is a hidden percentage: every one changes something you can watch happen
- `src/systems/summons.js` — the Summoner's army: a mossy **beast** that runs in and bites, a boxy **bot** that stomps, a static **turret** that tracks and fires. Timed rather than killable (a summon that can die turns every fight into babysitting) with a 16-unit leash so a beast cannot drag half the map back to you; hard cap of 8, oldest culled first
- `src/ui/awaken.js` — the awakening ritual (six cards, a branch row, and a **two-step confirm** — it is the only irreversible choice in the game and it sits one click from a card you might have clicked to read) + the skill-tree panel (K)
- `src/ui/lang.js` + `src/ui/prologue.js` — **EN/ID language pick** (English default, asked once per browser) and **THE PROLOGUE**: **ten** painted 320x180 pixel scenes with typed-on text. The shape is deliberate — it opens warm (SEMESTA: one world, counted), takes it away in the middle, and ends on one small job you can actually do, because a tragedy that ends in tragedy is a reason to stop playing. The grief is SPECIFIC: your mother walked the northern road for 22 years, told you "not past the gate" on the last ordinary evening, and her name is the eleventh of forty-one carved into the shrine wall because there was nothing to bury. Skippable from the first frame; glows are radial gradients, never `fillRect` (a square halo is the one thing that breaks the illusion of light)
- **`audio.setMood('story')`** — a fourth music set for the prologue AND the world build after it: three slow pieces (46/42/40bpm) in natural minor whose chord loops never resolve to the root on the last bar, so nothing feels finished while somebody is still reading. The title waltz is major and gentle; the prologue is about forty-one people who did not come back
- **WORLD DETERMINISM.** Camps, gathering nodes and chests are placed BEFORE the landmarks and write into the shared `decorBlocked` set and `foots[]`, so their `Math.random()` changed which of `place()`'s 140 attempts succeeded and moved every structure in the world with it. Measured before: **24 of 27 structures moved between two loads at identical settings, worst 110 units** — which is what made the same map look different on a phone and a desktop, nothing to do with the graphics preset. All three now use their own seeded stream. Measured after: **27/27 identical, drift 0.000**
- `src/systems/level.js` — **`MAX_LEVEL = 30`**. At the cap the XP bar reads full and stays there rather than filling and resetting forever

- `src/systems/items.js` — items w/ buy/sell coin prices, per-class weapons (4 tiers), fish, seeds/crops, cooked foods, 13 pet charms, 7 mount whistles, drop tables for 8 enemy types; **`RARITY`/`RARITY_ORDER`** — the six-tier ladder (common→uncommon→rare→epic→legendary→mythic, each with color + dupe refund) used by gacha, cosmetics & reveal FX; **28 wardrobe cosmetics** (`cosmetic: 'hat'|'back'|'trail'` + `rarity`): 13 hats (incl. chef toque, pirate tricorn, glowing pumpkin head, kitsune mask), 9 back pieces (incl. turtle shell, bobbing red balloon, swimming koi kite), 6 movement trails; **12 gacha-exclusive weapons** (`GACHA_WEAPONS`: epic Starforged / legendary Dragonfang / mythic Celestium × sword/bow/staff/dagger — each family has a **whole different silhouette** via `model: 'star'|'dragon'|'celestial'` → `buildExoticWeapon()` in player.js: STAR = faceted floating crystals (greatblade w/ loose orbiting shards, bow of 5 detached shards, monolith staff, shard-fan daggers), DRAGON = curved fangs & horns (serrated fang saber w/ dragon eye, horn bow w/ ember tips, talon-claw staff, karambit talons w/ knuckle ring), CELESTIAL = slim halos & crescents (halo saber, feather-wing bow, crescent-moon staff, moon-arc daggers); plus `glow` aura light + orbiting sparks, `anim` payload {ring/orb/floaters} animated in player.update, colored burst on every swing via main's `glowFx`; the pull matches the player's class weaponType, dupes skip to another prize); ALL crafted swords/daggers carry a bright glint edge strip, staff rings precess & orbs breathe (`getWeaponAnim`)
- `src/systems/cosmetics.js` — wardrobe system: procedural cosmetic meshes (straw/leaf/bandana/miner/wizard/catears/viking/crown/halo hats; pack + 5 wing styles incl. hue-cycling Prism; `TRAILS` particle configs incl. rainbow), `wing()` now builds **layered feathered wings** — each side is a fan of 4 overlapping teardrop feathers (long→short, colorA→colorB) + a quill spine + a glowing shoulder gem, with `wingRoots` pivots flapped in a two-stage beat; `createWardrobe(player)` attaches hats to `parts.head` / back gear to `parts.body`, animates (halo spin, wizard star orbit, crown gem pulse, cat-ear twitch, wing flap, balloon bob, koi sway, phoenix light flicker, prism hue), `trailColor(time)` feeds main's trail emitter, serialize/load
- `src/systems/skills.js` — 21 skills with cooldowns & juicy FX (shockwaves, light flashes, screen shake; EVERY cast also blooms a rotating **magic rune circle** (`particles.runeCircle` — sigil canvas: rings/notches/diamonds/triangle, additive, ease-out grow + fade, size scales w/ skill level) + spark burst + light flash in the skill's icon color); Berserker (rage/cleave/leapslam), Hunter (volley/snipe/beasttrap), Priest (heal/smite/bless) + skill leveling (Lv1-5: +22% power, -6% cooldown, longer buffs per level; 1 skill point per character level, spent in the K panel)
- `src/systems/quests.js` — quest chain + mount quests (simple deliveries → world boss hunts) + repeatable grind quests (kill/kill_any/fish/chest/forge/deliver/talk objectives; `worldboss` kill target), tracker lines, save/load
- `src/systems/pets.js` — 13 collectible pet companions: 10 from chests / world bosses / quests + 3 **gacha-exclusive** (`gachaOnly: true` — Glimmer crystal fox, Nox shadow imp, Seraphi mythic gold dragon w/ point-light glows); follower AI, passive perks (speed/dmg/regen/atkSpeed/xp/armor/crit/stamRegen/magnet/fish)
- `src/systems/mounts.js` — 8 rideable mounts: Sprig (starter, free), Trotter/Clucky/Shellsworth/Nimbus (quests), **Pebble (gacha epic — boulder puppy w/ mossy back, +armor)**, Blossom (gacha legendary, petal trail), **Aurora (gacha MYTHIC — translucent spirit elk w/ glowing antlers, waving aurora ribbons, shimmer particles, floats)**; mesh attaches under the player, gallop anim, speed/jump multipliers; def ORDER matters — `toggleMount` rides the last owned def
- `src/systems/fishing.js` — shore fishing minigame (cast → wait → "!" → strike) with full visual kit: rod in hand (bends in rhythmic TUGS on bite — deliberately not a vibrating blur), sagging line, bobber ripples, a real **fish silhouette** (body + side fins + wagging tail on a pivot) that glides in with an S-weave and circles under the float, catch arcs to the player with a droplet trail; SFX are pure soft sines (NO noise buzz — gentle cast swish, low plop, marimba bite boop); the bite anim is eased tug-pulses with rest beats between them, rod lerps smoothly; AFK mode (G) auto-fishes with heavily nerfed rarity

- `src/entities/enemies.js` — 14 enemies with cute critter-face styling, melee/ranged/charge AI (aggro ranges deliberately modest — exploring shouldn't trigger dogpiles; ALL monsters incl. - **FACING CONVENTION** (get this wrong and everything moonwalks or crabs sideways): headings use `atan2(dx, dz)` and movement is `(sin d, cos d)`. ## Multiplayer & accounts (live)

- `server/` — the authoritative half, running on a VPS behind a Cloudflare Tunnel. Owns the clock, weather, monster spawning and AI, the world boss, shared farm plots and chat. **The map is never sent**: every client generates a byte-identical world from fixed seeds, which is why one small box is enough. Interest management caps each player's feed at a 70-unit radius; positions go out at 8Hz as TARGETS, and the client eases between them
- `src/net/` — `auth.js` (Supabase: Google sign-in in-page via ID token so the consent screen names the game, not the database; cloud saves with a local-first, ask-when-close reconcile), `client.js` (reconnecting WebSocket; being offline is a normal state, not an error), `remote.js` (other players built with the SAME `buildCharacterMesh` as the hero, so their outfit is really theirs; walk animation derived from distance moved so no animation state crosses the wire)
- `src/ui/chat.js` — world chat: fades when idle, and remote text is inserted with `textContent`, never `innerHTML`. **The element is parented to `document.body`, not to `#hud`** — `#hud` carries `z-index: 10` and therefore its own stacking context, so chat's `z-index: 40` was scoped INSIDE it and could never rise above `#touchui` at 20; the button was drawn, sat under the joystick zone, and every tap on it moved the character. Position in the tree, not the number, was the whole problem — it now sits at z 30, above the touch controls and below dialogs (40) and the map (60). There is a real **💬 CHAT button** (Enter is only a desktop shortcut): on a phone it is a 46px icon pinned into the measured gap between the HP plate (ends x=188) and the minimap (starts x=269), the one patch of screen no gesture zone claims, and while typing the input box **pins to the TOP** because the on-screen keyboard covers the bottom ~300px
- `src/net/remote.js` — other players, built with the same `buildCharacterMesh` the hero uses. Positions arrive 8×/s and the screen redraws 60×, so every body EASES toward its target and derives its walk from how far it actually moved — no animation state crosses the wire. Also carries **their weapon, their pet, their swing and their speech**: `applyGear` calls the rig's own `setWeapon` and builds the pet from `PET_BUILDERS` (both looked up in OUR tables, so an id we don't know draws nothing); a swing is TRIGGERED by `p.a === 'atk'` and then plays out locally at full framerate (reading the flag as a pose gives a three-frame twitch); pets are parented to the SCENE and trot to catch up rather than being bolted behind their owner like a trailer; chat floats as a canvas **speech bubble** over the speaker's head (`say`), and `sayLocal`/`bindSelf` do the same for your own messages
- `src/net/protocol.js` + `server/src/protocol.js` — **`GEAR`** carries weapon/pet/mount ids in BOTH directions, sent only when they change (the client de-duplicates, so main.js can safely call `net.gear()` every frame) — a weapon id is a string and paying for it 8×/s to say "still the same sword" would be absurd
- **THE PORT 443 TRAP**: some hosts run an allowlist you cannot change. Symptom: port 80 works, Let's Encrypt succeeds, Caddy answers 308, and 443 times out with no TLS handshake — everything inside the VPS is correct, which sends you looking there for hours. `server/deploy/setup-tunnel.sh` sidesteps it: cloudflared dials OUT, so no inbound port exists to block
- **`lighting.state` is `minutes`, not `time`.** Three call sites used the wrong name and silently evaluated `undefined / 60` → NaN, so every night check read as day and night-only fish and dailies could never fire

### Solo vs online

The menu has **two doors, not one**: NEW ADVENTURE / CONTINUE build a private world, and **🌐 PLAY ONLINE** (shown only when `VITE_GAME_SERVER` is set) connects to the shared one. `main.js` gates `serverConfigured()` behind that choice — having a server configured must never push somebody into a world with strangers in it. Going online with a hero already made carries that hero in rather than forcing character creation again. Signed-in players also get **DELETE PROFILE** in the account strip: two-step (the button changes to REALLY DELETE? and re-arms after 4s), removes the Supabase `saves` row via `deleteCloudSave()` (RLS restricts it to the owner) AND the local save, because otherwise CONTINUE would resurrect what was just deleted.

## Conventions

- All in-game text & code comments are in English — including anything a third party renders for us. Google's sign-in button localises itself from the browser's language, which put one Indonesian string in the middle of an otherwise English game; the fix is `?hl=en` on the **GIS script URL**, not the `locale` option on `renderButton`, which does not override a script that has already resolved its language
- Never add image/audio asset files — everything stays procedural (canvas/WebAudio) per the original design. The ONLY exceptions are the two branding images in `logoasset/` (logo + creator mascot)
- Color palette is locked in `PALETTE` (src/gfx/textures.js) — keep the cozy 2.5D voxel style consistent
- `window.__semesta` exposes the live systems for automated verification
